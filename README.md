# video_learn_helper

视频（课程/演讲）学习辅助工具：本地/B站视频播放 + 字幕同步跳转 + ASR 转录 + AI 问答。

## 功能

- **视频**：打开本地视频（先播后存到本地库）；B站链接解析（yt-dlp），支持多P选集与清晰度选择，在线串流播放（未登录 360p~720p）。同一视频会记住播放进度；支持 0.5x / 1x / 1.25x / 1.5x / 2x 倍速（每次打开默认 1x）。首页最近播放显示 5 条，更多进「最近播放」页，可按标题搜索。
- **字幕**：SRT 上传、B站官方字幕（需 cookies）、ASR 实时转录（边看边转）三种来源；列表与播放进度双向同步，点击跳转。
- **AI 问答**：OpenAI 兼容协议（DeepSeek/OpenAI），多轮对话按视频保存在本地库、视频总结注入、可选「发送当前字幕」「发送当前视频帧」「思考」，SSE 流式输出。「对话设置」可配置是否注入视频总结/完整字幕、当前字幕前后携带条数，以及可选的自动压缩（到设定 k token 时把此前问答压成摘要）。上下文满了会在对话区报错，可选择开启新对话或压缩上下文；旧消息留在上面，中间用分隔线标出。视频全屏时可用快捷键（默认 Alt+A，可在设置里改）或控制条「AI」按钮唤起悬浮问答窗，样式与主界面问答区相同，可拖动、可缩放，方便看到不懂的地方立刻问。

## 前置条件

- Python ≥ 3.13，[uv](https://docs.astral.sh/uv/)
- 系统安装 **ffmpeg**（`ffmpeg` / `ffprobe` 在 PATH 中）

## 快速上手

### 1. 安装依赖

```bash
uv sync
```

ASR（默认 Silero VAD + SenseVoiceSmall / faster-whisper）已包含在 `uv sync` 中。首次转录会下载模型文件（约几百 MB），可能需要几分钟。

### 2. 启动服务

```bash
uv run python main.py --port 8000
# 打开 http://127.0.0.1:8000
```

如果想局域网访问，用 `--host 0.0.0.0`：

```bash
uv run python main.py --host 0.0.0.0 --port 8000
```

启动后浏览器打开首页（landing 页），会看到「打开一个课程或演讲，边看边问」，下面有「加载 B站视频」「打开本地视频」两个按钮。

### 3. 添加视频

- **本地视频**：点「打开本地视频」，选择本地 mp4 等文件。文件会上传到本地库，之后可随时打开。
- **B站视频**：点「加载 B站视频」，粘贴 B站链接或 BV 号，等解析出信息后选择分P和清晰度，点「在线播放」即可串流观看（未登录通常只有 360p~720p）。

播放器底部控制条支持：播放/暂停、进度条、清晰度切换（B站）、倍速（0.5x–2x）、字幕开关、音量、全屏。

### 4. 配置 AI 问答（第一次提问前必配）

AI 问答需要至少一个 LLM 提供商（OpenAI 兼容协议）。打开右上角 **⚙ 设置** → **LLM**：

- 选择已有提供商，或在「新增提供商」里填入：
  - **名称**：随意（如 `deepseek`、`moonshot`）
  - **Base URL**：如 `https://api.deepseek.com`
  - **API Key**：你的密钥
  - **模型**：用手填或点「拉取列表」自动获取
- 如果模型支持图片（发送视频帧），勾选「模型支持图像识别（可发送视频帧）」。

也可以不用界面，直接用环境变量覆盖（作用于当前激活的提供商）：`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。设置会持久化到 `data/config.json`，下次启动仍生效。

> 提示：没有配置 LLM 也能播放视频、转录字幕、导入 SRT、拉 B站官方字幕，只是「AI 问答」区不能提问。

### 5. 让 AI 能看到视频内容（获取字幕）

提问前先给视频配上字幕，三种方式任选：

- **ASR 实时转录**（推荐，最省事）：字幕区右上角 **⋮** →「开始实时转录」。边看边转，字幕增量出现在字幕列表；首次会下载约几百 MB 模型，等一会儿。也可点「停止转录」结束。
- **导入 SRT**：字幕区 **⋮** →「导入 SRT」，选择本地 `.srt` 文件。
- **B站官方字幕**：字幕区 **⋮** →「拉取 B站官方字幕」。需要先在 ⚙ 设置里上传 cookies（见下）。

转录/导入后，字幕列表与播放进度双向同步（当前句高亮、自动滚动），**点击某条字幕会跳转到对应时间点**。

> 没有字幕时，问答区会提示「当前视频没有字幕…」，你可以直接点「开始转录」或「导入 SRT」，或点「知道了」继续提问别的话题。

### 6. 提问

在右侧「AI 问答」区输入框输入问题，按 **Enter** 发送（Shift+Enter 换行）。每轮对话按视频保存在本地库，下次打开同一视频还在。

输入框上方有三个可勾选的辅助项：

- **字幕**：把当前这句字幕（及其前后若干条）一并发给 AI，适合问「这个 / 为啥」这种指代性问题。
- **画面**：把当前视频画面发给 AI（需模型支持图像识别）。
- **思考**：临时开启模型推理过程（需模型支持）。

点问答区右上角 **⋮** 可以「生成视频总结」「清空对话」；「对话设置」里可配置每次提问时注入视频信息/总结/完整字幕、当前字幕前后携带条数、以及自动压缩。

### 7. （可选）全屏悬浮问答

视频全屏后按默认快捷键 **Alt+A**，或点控制条的「AI」按钮，会唤起一个悬浮问答窗（样式与主界面问答区相同，可拖动、可缩放）。这样看到不懂的地方可以立刻问，不用退出全屏。

### 8. （可选）B站官方字幕的 cookies

拉取 B站官方向量需要登录态。在 ⚙ 设置 → **B站 cookies** →「上传 cookies.txt」，上传 Netscape 格式的 cookies 文件（存为 `data/cookies.txt`）。上传后在设置面板会显示状态，未上传时「拉取 B站官方字幕」会提示不可用。

## 配置

右上角「⚙ 设置」面板，运行期可改，持久化到 `data/config.json`。想直接用模板快速开始？仓库根目录附带 `config.example.json`（全部为占位符），复制到 `data/config.json` 后把 `api_key` 换成你自己的即可：

```bash
cp config.example.json data/config.json
```


- **LLM**：提供商选择、模型（可拉取列表）；「提供商设置 / 新增提供商」弹窗维护各提供商的 base_url、api_key、是否支持图像识别（deepseek 不支持图片，「发送当前视频帧」自动禁用）。也可用环境变量覆盖：`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。「思考」（渲染模型推理过程）在问答区按需临时开启。
- **B站 cookies**：上传 Netscape 格式 cookies.txt（存为 `data/cookies.txt`），用于拉取 B站官方字幕。
- **ASR**：默认 SenseVoiceSmall（配合 Silero VAD），也可选 faster-whisper；设备（cpu/cuda）、语言（默认 auto）。首次转录会下载模型权重。
- **快捷键**：全屏唤起 AI 问答（默认 Alt+A）。点设置里的按键后按下新组合即可修改，需包含 Ctrl / Alt / Meta，或使用 F1–F12。

## 项目结构

见 `PLAN.md` 第三节。

**数据存在哪：**

- **用户库（`data/videos/`，已 gitignore）**：视频列表、播放进度、字幕、总结、对话、本地上传的视频文件。同一台机器上换浏览器仍在。
- **工作缓存（同目录下的音频 / HLS 分片，以及 `data/config.json`、cookies）**：转录、串流代理、LLM/ASR 配置。
- **UI 状态（浏览器 localStorage）**：三栏布局、隐藏面板、输入框高度、画面字幕开关、对话上下文设置（含自动压缩）、全屏悬浮问答的快捷键与窗口位置/大小。换浏览器会丢，不影响学习内容。
