# video_learn_helper

视频（课程/演讲）学习辅助工具：本地/B站视频播放 + 字幕同步跳转 + ASR 转录 + AI 问答。

## 功能

- **视频**：打开本地视频（先播后存到本地库）；B站链接解析（yt-dlp），支持多P选集与清晰度选择，在线串流播放（未登录 360p~720p）。同一视频会记住播放进度；支持 0.5x / 1x / 1.25x / 1.5x / 2x 倍速（每次打开默认 1x）。首页最近播放显示 5 条，更多进「最近播放」页，可按标题搜索。
- **字幕**：SRT 上传、B站官方字幕（需 cookies）、ASR 实时转录（边看边转）三种来源；列表与播放进度双向同步，点击跳转。
- **AI 问答**：OpenAI 兼容协议（DeepSeek/OpenAI），多轮对话按视频保存在本地库、视频总结注入、可选「发送当前字幕」「发送当前视频帧」「思考」，SSE 流式输出。「对话设置」可配置是否注入视频总结/完整字幕、当前字幕前后携带条数，以及可选的自动压缩（到设定 k token 时把此前问答压成摘要）。上下文满了会在对话区报错，可选择开启新对话或压缩上下文；旧消息留在上面，中间用分隔线标出。视频全屏时可用快捷键（默认 Alt+A，可在设置里改）或控制条「AI」按钮唤起悬浮问答窗，样式与主界面问答区相同，可拖动、可缩放，方便看到不懂的地方立刻问。

## 前置条件

- Python ≥ 3.13，[uv](https://docs.astral.sh/uv/)
- 系统安装 **ffmpeg**（`ffmpeg` / `ffprobe` 在 PATH 中）

## 安装与运行

```bash
uv sync

# 启动
uv run python main.py --port 8000
# 打开 http://127.0.0.1:8000
```

ASR（默认 Silero VAD + SenseVoiceSmall）已包含在 `uv sync` 中。首次转录会下载模型文件（约几百 MB），可能需要几分钟。

## 配置

右上角「⚙ 设置」面板，运行期可改，持久化到 `data/config.json`：

- **LLM**：提供商选择、模型（可拉取列表）；「提供商设置 / 新增提供商」弹窗维护各提供商的 base_url、api_key、是否支持图像识别（deepseek 不支持图片，「发送当前视频帧」自动禁用）。也可用环境变量覆盖：`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。「思考」（渲染模型推理过程）在问答区按需临时开启。
- **B站 cookies**：上传 Netscape 格式 cookies.txt（存为 `data/cookies.txt`），用于拉取 B站官方字幕。
- **ASR**：默认 SenseVoiceSmall（配合 Silero VAD），也可选 faster-whisper；设备（cpu/cuda）、语言（默认 auto）。首次转录会下载模型权重。
- **快捷键**：全屏唤起 AI 问答（默认 Alt+A）。点设置里的按键后按下新组合即可修改，需包含 Ctrl / Alt / Meta，或使用 F1–F12。

## 测试

```bash
uv run pytest
```

## 项目结构

见 `PLAN.md` 第三节。

**数据存在哪：**

- **用户库（`data/videos/`，已 gitignore）**：视频列表、播放进度、字幕、总结、对话、本地上传的视频文件。同一台机器上换浏览器仍在。
- **工作缓存（同目录下的音频 / HLS 分片，以及 `data/config.json`、cookies）**：转录、串流代理、LLM/ASR 配置。
- **UI 状态（浏览器 localStorage）**：三栏布局、隐藏面板、输入框高度、画面字幕开关、对话上下文设置（含自动压缩）、全屏悬浮问答的快捷键与窗口位置/大小。换浏览器会丢，不影响学习内容。
